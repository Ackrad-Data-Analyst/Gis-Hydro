# Eight-week development plan

1. **Current:** safe project intake, inventory, source register, gaps, reports, tests.
2. Obtain Civil Engineering approval for category criticality and classification rules.
3. Design approved public/project data collection and provenance controls.
4. Add metadata validation for CRS, units, datum, coverage, and quality.
5. Prototype terrain, watershed, and drainage preparation on approved synthetic/public data.
6. Screen crossings and prepare preliminary model inputs.
7. Profile HEC-RAS workflows and expand QA/QC only after specialist review.
8. Summarize constraints, timing, documentation, and demonstration findings.

Each phase requires a small reviewed change with tests; later modules are not implemented now.
