# Instructions for future Codex sessions

1. Read `PROJECT_SCOPE.md`, `REQUIREMENTS.md`, and `ENGINEERING_RULES.md` before changing code.
2. Never modify, rename, move, delete, or overwrite original project data.
3. Work only in `data/working`, `outputs`, `logs`, `tests`, and source-code folders.
4. Do not invent engineering values; label engineering decisions **REVIEW REQUIRED**.
5. Do not add dependencies without documenting and justifying them first.
6. Make one small change at a time.
7. Add or update synthetic tests for every important change.
8. Run all tests before reporting completion.
9. Explain changed files in plain English and report commands and test results.
10. Do not configure or push to a remote repository.
11. Never use company data in tests; use synthetic fixtures only.
12. Clearly identify incomplete, uncertain, and future work.
13. Never claim this prototype produces final engineering approval.
